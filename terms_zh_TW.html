歡迎您使用「小火箭」（以下簡稱「本應用」或「平台」）提供的相關服務。

在您註冊、登入、使用本應用前，請您仔細閱讀並充分理解本《使用者協議》（以下簡稱「本協議」）的全部內容。您點選「同意」、註冊帳號、登入或使用本應用服務，即表示您已閱讀、理解並同意接受本協議的約束。

如您不同意本協議任何內容，請勿註冊、登入或使用本應用服務。

一、服務說明

  1. 本應用向使用者提供包括但不限於：
    • 即時通訊服務
    • 使用者帳號服務
    • 平台提供的其他加值服務
  2. 平台有權根據業務發展需要，對服務內容進行調整、升級或優化，並透過公告、通知等方式向使用者說明。
  3. 部分服務可能由第三方合作方提供，使用者使用相關服務時，應同時遵守第三方相關規則。

二、帳號註冊與使用

  1. 使用者可透過電子郵件方式註冊平台帳號。
  2. 使用者應保證註冊資訊真實、準確、完整，並妥善保管帳號及密碼資訊。
  3. 使用者不得：
    • 冒用他人身分註冊帳號
    • 出售、出租、轉讓帳號
    • 使用帳號進行違法違規活動
  4. 如發現帳號存在安全風險，平台有權採取限制登入、暫停使用等措施。
  5. 邀請碼規則：
    1. 註冊時邀請碼屬於選填項，為使用者自願行為，邀請碼可用於記錄使用者推薦關係。
    2. 邀請碼不會影響使用者帳號註冊，也不會限制使用者使用平台基礎服務。
    3. 邀請碼不代表任何付費資格、特殊權益或進階功能權限，使用者是否填寫邀請碼不會影響帳號功能使用。
    4. 使用者應確保所填寫的邀請碼來源真實有效，不得透過惡意註冊、虛假邀請等方式獲取不當利益。
    5. 平台有權根據業務規則調整邀請碼相關功能及權益，並透過應用內公告或其他方式進行通知。

三、使用者行為規範

使用者在使用本應用過程中，應遵守法律法規及平台規則，不得：

  1. 發布、傳播違法違規資訊
  2. 利用平台進行詐騙、賭博等違法活動
  3. 惡意攻擊、干擾平台正常運作
  4. 侵犯他人隱私、智慧財產權或合法權益
  5. 使用自動化工具惡意獲取平台資料

如使用者違反相關規定，平台有權採取包括但不限於：

  • 刪除相關內容
  • 限制部分功能
  • 暫停或關閉帳號
  • 配合有關部門調查

四、聊天服務規則

  1. 使用者透過本應用進行聊天交流時，應自行承擔資訊發布及傳播責任。
  2. 使用者不得利用聊天功能傳送違法、有害或侵犯他人權益的資訊。
  3. 平台可能根據法律法規及安全需要，對違規內容進行處理。
  4. 使用者理解並同意，平台不對使用者之間產生的交流內容承擔責任。

五、使用者資訊保護

  1. 平台重視使用者個人資訊保護，將按照《隱私權政策》蒐集、使用和保護使用者資訊。
  2. 使用者使用本應用，即表示同意平台按照《隱私權政策》的約定處理相關資訊。
  3. 使用者可透過平台提供的方式查看、更正或申請刪除個人資訊。

六、智慧財產權

  2. 未經平台書面許可，使用者不得複製、傳播、修改或用於商業用途。

  1. 平台可能因系統維護、升級、故障或其他原因暫停部分服務。

  3. 如使用者違反本協議，平台有權暫停或終止向使用者提供服務。

平台有權根據業務發展及法律法規變化，對本協議進行更新。

協議更新後，平台將在應用內進行提示。

若使用者繼續使用本應用服務，即視為接受更新後的協議內容。

十、帳號註銷

使用者可透過平台提供的帳號註銷入口申請註銷帳號。

帳號註銷後：

  • 使用者帳號相關服務將停止
  • 相關資料處理方式按照《隱私權政策》執行
  • 法律法規要求保存的資訊除外

如使用者與平台發生爭議，雙方應友好協商解決；協商不成時，按照相關法律規定處理。
